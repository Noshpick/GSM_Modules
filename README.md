1. Запускать сразу со всеми модулями что хотите использовать (опционально для первого запуска)
2. Перед запуском зайдите в server -> config -> config.json и введите пароль от sudo
3. Ссылка по которой можете посмотреть всю информацию по модему и смс localhost:7777/audit
4. Ссылка для просмотра через клиент localhost:3000
5. Клиент быстрее подгружает и выводит информацию.

6. Curl запрос на получение кодов от номера:

*curl -X GET "http://localhost:7777/code?phone=ТУТ_НОМЕР_БЕЗ_ПЛЮСА"*

7. В клиенте выводятся логи которые обновляются каждые 5 секунд. Так же обновляются смс каждые 10 секунд.

8. Если какой-то из модулей перестанет функционировать во время работы с остальными, программа продолжит работать и будет удалять не работающий модуль чтобы не делать лишних запросов.
