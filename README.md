1. Запускать сразу со всеми модулями что хотите использовать (опционально для первого запуска)
2. Ссылка по которой можете посмотреть всю информацию по модему и смс localhost:7777/audit
3. Ссылка для просмотра через клиент localhost:3000
4. Клиент быстрее подгружает и выводит информацию.

5. Curl запрос на получение кодов от номера:

*curl -X GET "http://localhost:7777/code?phone=ТУТ_НОМЕР_БЕЗ_ПЛЮСА"*

6. В клиенте выводятся логи которые обновляются каждые 5 секунд. Так же обновляются смс каждые 10 секунд.

7. Если какой-то из модулей перестанет функционировать во время работы с остальными, программа продолжит работать и будет удалять не работающий модуль чтобы не делать лишних запросов.
